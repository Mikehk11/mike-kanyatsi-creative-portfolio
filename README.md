# Mike Kanyatsi — Creative Web Portfolio

A bilingual, motion-led portfolio for an independent web designer and creative developer serving Ottawa, Montréal, and businesses across Canada.

## Highlights

- English and French presentation
- Responsive editorial layout
- Lightweight CSS-built 3D artwork and motion
- Services, process, pricing, and concept case studies
- Accessible reduced-motion support
- Production-ready Next.js deployment

## Live site

https://mike-kanyatsi-creative-portfolio.vercel.app

## Local development

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Production

```bash
npm run build
npm start
```
